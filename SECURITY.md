## Reporting a Vulnerability
Please report all security vulnerabilities privately to prevent active exploitation before a patch is available. Do not open a public GitHub issue for security-related bugs.

**How to Report**
Submit a private vulnerability report directly through the repository:

1. Navigate to the **Security** tab of this GitHub repository.
2. Click **Advisories** in the left sidebar, then select **Report a vulnerability**.
3. Provide concrete steps to reproduce the exploit, attaching any necessary malformed save files, network packets, or memory manipulation logs.

**Response Process**

* **Acknowledgement:** You will receive an initial response confirming receipt and triage status within 48 hours.
* **Evaluation:** The maintainers will assess the report to confirm the impact (e.g., arbitrary code execution, buffer overflows, or local privilege escalation via the 3DS OS).
* **Resolution:** If the vulnerability is accepted, we will collaborate with you on a private patch and credit you in the ensuing security advisory and release notes. If declined (e.g., the issue stems from a known emulator bug rather than the game engine itself), we will provide a clear technical explanation before closing the report.
